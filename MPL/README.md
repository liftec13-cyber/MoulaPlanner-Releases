# MoulaPlanerLoot

Install the MoulaPlanerLoot folder in Interface/AddOns. Preserve your existing SavedVariables, loot sessions and awards. Never replace WTF or SavedVariables from a ZIP. Preserve an existing DesktopPatch.lua during an update.

MPL Patch Available uses its own version and official download link. MPD supplies the metadata; WoW requires addon load or a manual reload to read refreshed Desktop files. No HTTP or automatic installation occurs in Lua. Copy Link selects the link for Ctrl+C. Close remembers the dismissed version independently of MPT.

Without MPD, use the public GitHub Releases page manually. The existing MPL MIT license and third-party attributions are preserved verbatim, including its existing copyright notice.
