# MoulaPlanner — Downloads

Public distribution of MPD, MPT and MPL. Only runtime ZIPs, version manifests and user documentation belong here. The development repository remains private.

Each product has its own version and Release tag: mpd-vVERSION, mpt-vVERSION, mpl-vVERSION. Download the ZIP and manifest.json from the same Release and compare the ZIP SHA-256 before installation. Do not run an archive with a mismatched digest.

MPD requires Windows x64 and .NET Framework 4.8. MPT and MPL target World of Warcraft Forever, interface 16001. The addon ZIPs necessarily contain their runtime Lua files. No desktop/server development sources, tests, credentials, SavedVariables or player data are distributed.

See the MPD, MPT and MPL folders for installation and update instructions. Existing product and third-party licenses remain included in their ZIPs. No automatic installation is provided.
