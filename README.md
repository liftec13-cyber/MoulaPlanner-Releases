# MoulaPlanner — Addon downloads

Public distribution of MoulaPlannerTools (MPT) and MoulaPlanerLoot (MPL). This repository contains runtime addon ZIPs, manifests and user documentation only. The development repository remains private.

Use the mpt-vVERSION and mpl-vVERSION Releases. Download the ZIP and manifest.json from the same Release and verify the ZIP SHA-256 before installation. Preserve existing Desktop*.lua, WTF and SavedVariables files. No automatic installer is provided.

Both addons target World of Warcraft Forever, interface 16001. Runtime Lua and existing licenses remain included in their ZIPs. See the MPT and MPL directories for instructions.
