# MoulaPlannerTools

Install the MoulaPlannerTools folder in your game's Interface/AddOns directory. Preserve existing Desktop*.lua files during updates; use the neutral placeholders only for missing files on a first installation. Never replace WTF or SavedVariables from a download.

When MPD reads a verified public Release manifest, it writes version metadata through the existing Desktop-file exchange. WoW reads these files at addon load, so a manual reload or restart may be required. MPT never performs HTTP, downloads a ZIP or runs an installer.

MPT Patch Available shows your version and the newer one. Copy Link focuses and selects the official link; press Ctrl+C. Close dismisses that specific version persistently. Without MPD, visit this repository's Releases manually; no automatic Internet version discovery is promised in WoW.
